# Changelog

## [0.1.0]

### Added
- Add `word_count()` for counting words in text.
- Add `character_count()` for counting characters.
- Add `reverse()` for reversing text.
- Add `capitalize_words()` for capitalizing words.
- Add `snake_case()` for converting text to snake case.
- Add `text_statistics()` for computing text statistics.
- Add automated tests with pytest.
- Add code quality checks with Black and Ruff.
- Add package organization with public APIs through `__init__.py`.
- Add project configuration with `pyproject.toml`.
- Add GitHub Actions continuous integration.
